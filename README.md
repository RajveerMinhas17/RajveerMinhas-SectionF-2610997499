
# Client-Side-Technology-Assignments

HTML assignments for Client Side Technologies (CST), 1st semester.

**Name:** Rajveer Minhas
**Course:** BCA (AI/ML), Chitkara University

## Projects

| Folder | What it is |
|---|---|
| StudentResult | Student Examination Result table using rowspan and colspan |
| NestedTables | Salary slip, student profile, order summary and hotel booking tables |
| RestaurantMenu | Restaurant menu table with a caption |
| CourseRegistration | Online Course Registration form |
| ReadersHaven | Book registration and order form |
| MyCollege | College page with lists, images, links and bookmarks |
| WorldMap | World Map Explorer using an image map |
| FoodImageMap | Interactive restaurant menu using an image map |

## How to run

1. Download or clone the repo.
2. Open any folder.
3. Open its `index.html` in a browser (or use Live Server in VS Code).

## Topics covered

- Tables (border, cellpadding, cellspacing, rowspan, colspan, nested tables)
- Forms (input types, validation, radio buttons, checkboxes, drop-downs, textarea)
- Lists (ordered, unordered, nested, description)
- Images, links, bookmarks and image maps
